# WS2812B LED Strip Controller

Custom C++ firmware for controlling WS2812B addressable RGB LED strips.

## Hardware
- **Microcontroller:** ESP32 (np. ESP32-C3 / ESP32-S2)
- **LED Strip:** WS2812B (5V / 12V)

## Features
- Custom lighting animations and color transitions
- Smooth brightness and state control

## Build & Upload
Built using PlatformIO / Arduino framework in C++.
